## 3. Server Startup & Health Polling Protocol

1. **Existence Verification**: Check `fs.existsSync(pythonPath)` and `fs.existsSync(serverPath)`.
   - If missing: Show native `dialog.showMessageBox` in Vietnamese with guidance to check `README.md`, but do not crash; continue to open the main window.
2. **Process Spawn**:
   ```typescript
   const backendProcess = spawn(pythonPath, [serverPath], {
     cwd: path.dirname(serverPath),
     detached: false,
     stdio: 'ignore' // pythonw has no stdio
   });
   ```
3. **Health Poll Loop**:
   - Interval: Every $1000\text{ ms}$.
   - Max Retries: $60$ attempts ($60$ seconds).
   - Target: `GET http://localhost:8008/health`.
   - Success Condition: HTTP status `200` and response body `{ ok: true, model_loaded: true }`.
   - On Success: Resolve readiness state and load window URL.
   - On Timeout: Display warning alert and proceed to open window in degraded/fallback mode.

## 4. Lifecycle & System Tray Contract

- **Window Close (`close` event)**:
  ```typescript
  mainWindow.on('close', (event) => {
    if (!isQuitting) {
      event.preventDefault();
      mainWindow.hide();
    }
  });
  ```
- **System Tray Menu**:
  - Item 1: "Mở VoxRead" $\rightarrow$ `mainWindow.show(); mainWindow.focus();`
  - Item 2: Separator
  - Item 3: "Thoát" $\rightarrow$ Set `isQuitting = true`, kill Python backend process, call `app.quit()`.
- **Termination Handler (`before-quit` / `window-all-closed`)**:
  - On Windows, terminate child Python processes using:
    ```typescript
    if (backendProcess && backendProcess.pid) {
      exec(`taskkill /pid ${backendProcess.pid} /T /F`);
    }
    ```
  - Ensures no background `pythonw.exe` or PyTorch worker threads remain after application exit.
