# Implementation Plan: Legacy Chrome Extension Cleanup & Dynamic RVC Model Auto-Discovery

**Branch**: `026-cleanup-legacy-auto-model` | **Date**: 2026-09-05 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/026-cleanup-legacy-auto-model/spec.md`

## Summary

This plan outlines the complete implementation of repository hygiene, backend extension decoupling, dynamic model auto-discovery, and documentation alignment for VoxRead. The changes remove dead devDependencies (`@testing-library/user-event`, `autoprefixer`, `tsx`), update `.gitignore` cache and output patterns, remove Chrome extension origins and outdated docstrings from `python-backend/server.py`, replace hardcoded model filenames with automatic directory scanning of `python-backend/model/`, prevent server crashes when no model is installed (returning HTTP 503 from `/speak`), add `python-backend/model/.gitkeep`, update tests, and synchronize `README.md` and `docs/rvc-voice-setup.md`.

## Technical Context

**Language/Version**: TypeScript / Node.js 22, Python 3.10  
**Primary Dependencies**: Flask (^3.0.0), Edge-TTS (^6.1.9), rvc-python, React 19, Electron 44  
**Testing**: Vitest (`npm test`), Pytest (`pytest python-backend/tests`)  
**Target Platform**: Desktop (Windows 10/11 x64 via Electron) & Web (Vite + React)  
**Project Type**: Standalone E-Reader Desktop Application with Local Microservices  
**Performance Goals**: Model auto-discovery in < 5ms at server startup; 0 startup crashes when model is absent  
**Constraints**: Zero code edits required for users dropping models into `model/`; CORS restricted to localhost/127.0.0.1/null  
**Scale/Scope**: Repository configuration, Python backend server, Pytest test suite, and architectural documentation
